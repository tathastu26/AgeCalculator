# 🎂 Age Calculator

A responsive Age Calculator built with HTML, CSS, and JavaScript.

### Features
- Age in Years, Months, and Days
- Total Days, Hours, Minutes, and Seconds lived
- Birthday Countdown
- Day of Birth
- Life Statistics (Heartbeats & Breaths)

### Tech Stack
HTML • CSS • JavaScript
